# 图片格式转换 + 轻量编辑器

一个 Windows 桌面 GUI 应用，提供两大能力：

- **格式转换**：单个或批量把图片从一种格式转成另一种。
- **轻量编辑**：打开单张图片，进行裁剪和绘制标注，再保存。

## 功能

### 格式转换
- 支持格式：PNG、JPEG、WebP、GIF、BMP、ICO、TIFF、TGA、AVIF、PNM、QOI
- 单个 / 批量（多选、整个文件夹），并行处理
- 每格式参数：JPEG 质量（1–100）、PNG 压缩级别
- 透明图片转 JPEG/BMP 等不支持透明的格式时，自动合成背景色（可配置）
- 同名文件「跳过」或「覆盖」策略
- 进度条 + 逐文件结果

### 图片编辑
- 打开单张图片，画布支持滚轮缩放、右键拖动平移
- 绘制工具：自由画笔、直线、箭头、矩形、椭圆、文字标注
- **马赛克遮挡**（像素化遮挡敏感区域，可调强度）
- 颜色、线宽可调；撤销 / 清空标注
- **图片调整**：旋转 90°/180°/270°、水平/垂直翻转、灰度、反色、亮度/对比度/饱和度
- **滤镜**：高斯模糊、锐化、像素化
- 裁剪：自由选区 + 固定比例（1:1 / 4:3 / 16:9），选比例即时预览
- 文字标注：就地输入、可拖动移动、滚轮调整字号
- 保存：另存为新文件（选格式），或覆盖原图

### 批量转换增强
- **等比缩放**（指定目标宽度，Lanczos3）
- **文字水印**（右下角半透明）
- **文件名前缀**（批量输出统一加前缀）

## 运行

```bash
cargo run
```

## 打包发布

```bash
cargo build --release
```

产物为 `target/release/image-converter.exe`，单文件、双击即用、无需安装任何运行时。

## 说明

- WebP 当前为**无损**编码（`image` crate 原生仅支持无损；有损 WebP 需 libwebp 第三方 C 库，为保持零依赖未引入）。
- 文字标注的中文字体从系统加载（`C:\Windows\Fonts\msyh.ttc`），失败时回退到 Arial。

## 技术栈

Rust · eframe/egui · image · rfd · rayon · fontdue
